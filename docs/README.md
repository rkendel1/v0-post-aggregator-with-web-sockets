## Contributing Documentation

When adding new documentation:

1. **Guides**: Add feature-specific guides to `/guides/`
2. **Architecture Changes**: Update `ARCHITECTURE.md` in root
3. **Development Process**: Update `DEVELOPMENT.md` in root
4. **Completed Work**: Move to `/archive/` when no longer current

Keep documentation:
- Clear and concise
- Up to date with code
- Cross-referenced with related docs
- Focused on current state (not historical)
